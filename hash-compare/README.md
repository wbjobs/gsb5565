# 哈希表冲突解决策略对比工具

链地址法 vs 开放寻址法（线性探测 / 二次探测）的可视化对比工具。
技术栈：**Canvas + Web Worker + TypedArray**，零依赖，纯静态页面。

## 运行

```bash
cd hash-compare
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

> 需通过 HTTP 访问（Web Worker 不允许从 `file://` 加载）。

## 功能

- **两种冲突解决策略同屏对比**：链地址法（TypedArray 静态链表 `heads/next/keys`）
  与开放寻址法（`Uint8Array` 状态数组 + `Int32Array` 键数组），所有操作同时作用于两表。
- **插入 / 查询 / 删除**：单键操作与批量随机插入（最多 2 万个）。
- **哈希函数选择**：除留余数法、乘法散列（Knuth）、平方取中法。
- **探测方式选择**：线性探测 `(h+i) mod m`、二次探测 `(h+i²) mod m`（素数容量 + 兜底强制扩容）。
- **统计指标**：装载因子、累计冲突次数、平均插入/成功查询/失败查询探测长度、
  墓碑数量、扩容次数。
- **扩容**：装载因子超阈值（可配置）自动扩容至 2 倍后的下一个素数，全量 rehash，数据不丢。
- **墓碑标记**：开放寻址删除置 `TOMBSTONE`，查询越过墓碑、插入复用墓碑；
  墓碑过多时同容量重建清除。
- **空表查询**：直接返回未找到，UI 日志给出提示。
- **可视化**：
  - 链地址法：桶分布直方图（颜色随链长渐变）+ 链遍历过程 DOM 动画；
  - 开放寻址法：槽位网格（空/占用/墓碑着色）+ 探测路径逐槽动画（命中绿、未命中红）。
- **随机一致性测试**：Worker 内执行随机插入/删除/查询序列，逐步与参考 `Set` 比对两表结果。
- **主线程不卡**：全部计算在 Web Worker 中执行，快照通过 Transferable ArrayBuffer 零拷贝传递，
  主线程仅做 Canvas 渲染。

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` / `style.css` | 页面结构与样式 |
| `app.js` | 主线程：Canvas 渲染、探测动画、UI 交互 |
| `worker.js` | Worker：两种哈希表实现、统计、扩容、一致性测试 |
| `test-worker.js` | 核心逻辑验收测试（Node，vm 沙箱加载 Worker） |
| `test-ui.js` | UI 冒烟测试（DOM 桩 + 真实 Worker 集成） |

## 测试

```bash
node test-worker.js   # 6 种配置组合 × 13 项验收断言
node test-ui.js       # 完整用户操作流冒烟测试
```

## 验收标准对照

| 验收标准 | 实现与验证 |
| --- | --- |
| 两种策略查询结果一致 | 每次查询实时比对并显示一致性徽章；随机测试逐步与参考 Set 三方比对 |
| 装载因子/冲突次数统计准确 | 插入时首槽/首桶被占计 1 次冲突；装载因子 = size/capacity 实时显示 |
| 扩容后数据不丢 | rehash 全量迁移；测试断言扩容后 size 与参考 Set 一致 |
| 删除墓碑标记正确 | `TOMBSTONE` 状态、查询不断链、插入复用、网格橙色可视化 |
| 平均探测长度可量化 | 分别统计插入/成功查询/失败查询的累计探测次数与均值 |
| 桶分布可视化准确 | 直方图由快照 `heads/next` 实际遍历生成；槽位网格直接渲染 `state` 数组 |
| 主线程不卡 | 计算全部在 Worker；批量 2 万插入不阻塞 UI；快照零拷贝传输 |
